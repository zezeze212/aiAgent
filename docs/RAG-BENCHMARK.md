## 1. 阶段目标与完成范围

本阶段围绕正式 Spring AI Agent 完成：

- rule、vector、BM25、Hybrid/RRF 检索策略选择。
- 可选重排与正式知识链路集成。
- 可选查询改写与正式首次检索集成。
- 请求级知识去重、片段数量和字符预算。
- 可选请求级来源配额。
- 可选知识片段 token 估算预算。
- 引用 ID 审计与结构化引用出处。
- 检索、重排、查询改写评测及有限回答证据审阅。

正式问答入口仍为 POST /agent/ask。
独立 Benchmark 用于分析策略，不代替正式链路集成。

## 6. 上下文与引用工程结论

来源配额以请求为范围累计，仅对实际选入片段计数。
同一文档的多个片段可能分别提供原因和处理步骤，
来源更分散不等于证据更完整。

token 预算采用 CL100K_BASE_PROXY 估算：
- 前置阶段按单片段格式化文本估算并累计。
- 工具后阶段按单片段 JSON 表示估算并累计。
- 不包含完整系统提示、用户消息、工具定义、完整工具结果和输出。
- 不等同于 DeepSeek 精确 token 数，也不是计费统计。

最终引用允许集合只包含实际选入的片段。
结构化引用来自本次请求保存的片段，不重新检索补造出处。

VALID_IDS 只表示引用 ID 归属合法。
semanticSupportChecked=false 明确表示程序没有进行语义验证。

## 7. 有限回答证据检查

报告：

evaluation/rag/reviews/m6-6b/review.md

范围：一个历史工具样例与两个当前首次请求。

结论：
- 历史工具样例中选定的三个断言与工具结果一致。
- 当前知识回答的主要内容获得对应片段支持。
- 当前工具回答正确报告 created_time 默认值，
  并表示现有结果无法确认 id 是否自增。
- 附加说明仍存在无证据经验判断和检查方法粒度错误。
- NO_CITATIONS 不自动构成失败，工具事实可直接支持回答。

原始响应存在可逆编码错读，保留原件，
报告说明阅读时的还原方式；未定位具体发生环节。

这些样例不构成整体回答正确率或自动语义评测。

## 8. 策略决策

- 正式支持 rule、vector、bm25、hybrid。
- 保留仓库既有默认策略，不因单轮指标自动改为 Hybrid。
- 重排和查询改写保留可选开关，不要求默认开启。
- 来源配额和 token 估算预算按场景启用。
- 本阶段总结不修改用户当前启动配置。
- 不用同一批题反复调 Prompt 或挑选更好的模型回答。

最近 M6-6B 两份 Trace 观察到：
Hybrid、查询改写 APPLIED、来源配额关闭、token 预算关闭。
该观察不代表所有环境的配置。

## 9. 阶段限制与后续范围

本阶段未完成：
- 大规模或独立盲测语料上的泛化验证。
- 精确生成模型 token 预算。
- 自动引用语义验证或自动回答修复。
- 系统性的 chunk size / overlap 参数搜索。
- 完整租户授权和实验接口生产访问控制。
- 全部索引中断点的故障注入验证。

以上限制如实保留，不追加为 M6 收尾单元。
Multi-query、HyDE、Parent-Child、Graph RAG 不属于本轮必做范围。
